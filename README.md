# 🏠 싸피 홈 (SSAFY Home)

주변 인프라 기반 맞춤형 부동산 추천 서비스

---

## 1. 프로젝트 개요

### 프로젝트 소개
기존 부동산 플랫폼은 **매물 정보**는 제공하지만,  
사용자가 실제로 중요하게 생각하는 **주변 인프라 정보(학교, 역세권, 편의시설 등)** 를
한눈에 파악하기 어렵다는 문제점이 있다.

**싸피 홈**은 지도 기반 부동산 검색과 주변 인프라 분석을 통해  
사용자 맞춤형 매물을 추천하는 서비스이다.

---

### 기획 배경
기존 부동산 서비스를 이용할 때 사용자는 다음과 같은 불편함을 겪는다.

- 집을 검색한 뒤 다시 지도 앱으로 이동
- 주변 상권, 편의점, 지하철역, 학교 등을 별도로 검색해야 함
- 사용자마다 중요하게 생각하는 인프라가 다름
  - 대학생 → 역세권
  - 신혼부부 → 학교 / 마트
  - 노년층 → 병원 / 편의시설

---

### 핵심 아이디어
주변 인프라 데이터를 API로 수집하여  
거리, 중요도, 사용자 선호도를 반영한 **인프라 종합 점수**를 계산한다.

#### 지원 인프라
- 마트
- 편의점
- 학교
- 지하철역
- 식당
- 편의시설 (노래방, PC방 등)

```text
매물 검색

```

## 6. REST API 설계

> 전체 명세: [`docs/specs/rest-api-spec.md`](docs/specs/rest-api-spec.md)  
> Base URL: `https://{host}/api/v1`

### 인증 수준

| 수준 | 설명 |
|------|------|
| **Public** | JWT 불필요 |
| **Protected** | `Authorization: Bearer <AccessToken>` 필수 |

### 엔드포인트 목록

| ID | Method | Path | 인증 | 설명 |
|----|--------|------|------|------|
| MAP-01 | `GET` | `/api/v1/map/markers` | Public | 지도 Bounding Box 내 마커 조회 (줌 레벨에 따라 개별 마커 / 시·군·구 집계 자동 분기) |
| LOC-01 | `POST` | `/api/v1/location/score` | Protected | 좌표 + 카테고리별 가중치를 받아 입지 점수 산출 및 breakdown 반환 |
| PUB-01 | `GET` | `/api/v1/proxy/public-data` | Protected | 심야 배치 적재된 공공데이터 (실거래가 / 상권정보) 페이지네이션 조회 |
| PUB-02 | `GET` | `/api/v1/proxy/public-data/realtime` | Protected | 배치 미반영 당일 데이터 단건 실시간 중계 (인증키 은닉) |
| AI-01 | `POST` | `/api/v1/ai/property-summary` | Protected | 매물 정보 + 입지 점수를 LLM에 전달해 자연어 요약문 생성 |
| AI-02 | `POST` | `/api/v1/ai/review-summary` | Protected | 건물·지역 리뷰 목록을 LLM에 전달해 긍정·부정 테마 + 요약문 생성 |

### 주요 설계 원칙

- **좌표계**: EPSG:4326 고정. 파라미터 순서 `minLng,minLat,maxLng,maxLat`, lat/lng 뒤바뀜 자동 검증·거부
- **줌 분기**: 서버가 임계값(`≥15` = DETAIL, `≤14` = SUMMARY)으로 재판정. 클라이언트 값 불신
- **거대 bbox 가드**: 대각 > 150km + DETAIL 요청 시 400 거부. SUMMARY는 강제 다운그레이드
- **공간 쿼리**: `ST_DWithin(geom::geography, …, N)` + GiST 인덱스. `ST_Distance` 단독 사용 금지
- **AI Fallback**: LLM 장애 시 `summaryAvailable: false` 포함 HTTP 200 반환 (서비스 중단 없음)
- **캐싱**: SUMMARY 응답 ETag + 5분 TTL. AI 요약 MySQL `ai_summaries` 테이블 24h TTL
